스마트폰 & PC 음성 대화 꿀팁 가이드

가장 편리하고 끊김 없는 음성 대화 방법을 안내해 드립니다!

📱 스마트폰 최고 추천: [키보드 자판 마이크 🎙️]
스마트폰에서는 브라우저 마이크 권한과 무관하게, 자판의 마이크(🎙️ 받아쓰기) 버튼을 누르시는 것이 가장 편리하고 인식률이 압도적으로 높습니다!
✔ 삼성 갤럭시: 입력창 터치 → 키보드 상단 툴바의 마이크(🎙️) 터치 후 영어로 말하기 → [전송 🚀]
✔ 아이폰/아이패드: 입력창 터치 → 키보드 우측 하단의 마이크(받아쓰기 🎙️) 터치 후 말하기 → [전송 🚀]
💡 장점: 브라우저 권한 허용 불필요, 1회 차단 전혀 없음, 말한 뒤 오타 수정 가능, 100% 무제한 대화!
💻 PC 추천: [영어라운지_실행하기.bat] 더블 클릭
크롬은 로컬 파일(file://)에서 보안상 마이크를 1회만 임시 허용합니다.
폴더 안의 [영어라운지_실행하기.bat]를 더블 클릭하시면 로컬 서버(http://localhost:8000)로 열려, 크롬에서 마이크 권한이 영구 기억되어 수백 번 대화해도 끊김 없이 완벽하게 작동합니다!
💬 말문이 막힐 땐? [추천 힌트 칩] 터치!
화면 하단의 추천 힌트 칩(💡)을 클릭하시면, 직접 말하지 않아도 상황에 딱 맞는 원어민 표현이 즉시 발화되어 대화가 자연스럽게 이어집니다.

🔑 무료 Gemini AI 실시간 연결 설정

Google AI Studio의 무료 API 키를 등록하시면, 어떤 기상천외한 주제든 실시간 생성형 AI가 100% 새로운 동화와 맞춤 회화를 창작합니다!

💡 1분 만에 무료 API 키 받는 법:
1. Google AI Studio 키 발급 페이지 (클릭)에 구글 계정으로 로그인합니다.
2. 파란색 [Create API key] 버튼을 누르고 발급된 키를 복사합니다.
3. 아래 입력창에 붙여넣고 [🔍 연결 테스트하기]를 눌러 정상 작동을 확인하세요! (신용카드 등록 없는 100% 무료 키)
※ 키 앞뒤의 불필요한 공백이나 따옴표는 자동으로 제거됩니다.
💡 1.5/2.0 구버전 종료에 맞춰 최신 2.5/3.5/3.8 Flash 모델이 기본 지원되며, [연결 테스트] 시 계정에서 사용 가능한 모델을 자동 감지합니다.

🔒 입력하신 API 키는 브라우저 내부(localStorage)에만 안전하게 보관되며, Google 서버 호출 외에는 어디로도 전송되지 않습니다.
